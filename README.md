# Focus Tracker (자습 집중도 측정기)

**책상캠**과 **얼굴캠**, 마이크를 함께 사용해 실시간으로 학습 집중도를 측정하고, 과목별 학습 시간을 기록하며, 하루 학습이 끝나면 종합 평가를 보여주는 집중력 트래커입니다. **YOLO11(Ultralytics)**, **MediaPipe**, **OpenCV**를 기반으로 제작했습니다.

이 프로젝트는 **서울과학고등학교 동아리 LTE-ANN**의 2학년 7명이 함께 개발했습니다.

## 주요 기능

* **책상캠 (Camera1)** — YOLO11n 물체 감지로 책상 위에 휴대폰(산만 요소)이 있는지, 책/노트북(학습 아이템)이 있는지 판정
* **얼굴캠 (Camera2)** — MediaPipe Face Mesh + Face Detection을 이용한:
  * 시선(gaze) 추적 — "정면 응시" 기준으로 캘리브레이션 후 편차로 판정
  * 눈 깜빡임 / 눈 감김 감지 (EAR, Eye Aspect Ratio)
  * 눈 가림(occlusion) 감지 — 손이나 물체로 눈을 가린 경우
  * 고개 방향(head pose) 확인 — 정면을 유지하고 있는지
* **마이크 기반 소음 감지** — 조용한 상태를 기준값으로 캘리브레이션한 뒤, 그보다 시끄러워지면 소음으로 판정
* **가중치 기반 집중도 점수 산출** — 시선/고개/깜빡임/소음을 조합해 0~100점 점수를 만들고, 책상캠 결과와 다시 결합한 뒤 EMA(지수이동평균)로 스무딩
* **과목별 학습 기록** — 과목 시작/일시정지/이름변경/삭제, 과목별 누적 시간과 평균 집중도 확인
* **실시간 집중도 그래프** — 공부 중 집중도 점수 추이를 그래프로 표시
* **하루 종합 평가 화면** — 세션 종료 시 평균 점수, 5단계 집중 등급, 시간대별 그래프, 과목별 통계 제공
* **자동 종료 안전장치** — 얼굴이 10초 이상 인식되지 않으면 세션 자동 종료, 눈을 3초 이상 감고 있으면 경고 표시
* **시작 튜토리얼** — 처음 사용하는 사람도 카메라 배치, 캘리브레이션, 과목 목록 사용법을 안내받을 수 있음
* **한글 UI 렌더링** — OpenCV의 기본 `putText`는 한글을 지원하지 않기 때문에, Pillow 기반 자체 텍스트 렌더러로 한글 라벨을 정상 출력
* **두 가지 실행 모드**:
  * **데스크톱 모드** (`main_ver5.py`) — 기존 OpenCV 창 방식
  * **웹 모드** (`main.py`) — FastAPI + MJPEG 스트리밍으로 동일한 트래커를 로컬 브라우저 탭에서 실행, 클릭/키 입력도 페이지에서 서버로 전달

## ⚠️ 설치 및 환경 설정

이 프로젝트는 **Python 3.11**을 필요로 합니다.

> **참고:** `mediapipe` 라이브러리가 아직 최신 Python 버전(3.12 이상)을 지원하지 않습니다. 반드시 Python 3.11 기반의 가상환경을 사용해야 합니다.

### 빠른 시작

#### 1. Python 3.11 설치

시스템에 Python 3.11이 설치되어 있는지 확인하세요.

#### 2. 가상환경 생성

터미널에서 이 프로젝트 디렉터리로 이동한 뒤, 사용 중인 Python 3.11 설치 방식에 맞는 명령어를 실행하세요.

```bash
# Linux/macOS ('python3.11' 명령어를 사용할 수 있는 경우):
python3.11 -m venv .venv

# Windows (공식 인스톨러로 설치한 경우):
py -3.11 -m venv .venv

# Python 3.11이 기본 'python3' 명령어인 경우:
python3 -m venv .venv
```

#### 3. 가상환경 활성화

운영체제에 맞는 명령어를 실행하세요.

```bash
# Linux/macOS:
source .venv/bin/activate

# Windows (명령 프롬프트):
.\.venv\Scripts\activate.bat

# Windows (PowerShell):
.\.venv\Scripts\Activate.ps1
```

#### 4. 의존성 설치

가상환경이 활성화된 상태에서 패키지를 설치하세요.

```bash
pip install -r requirements.txt
```

OpenCV, MediaPipe, NumPy, sounddevice, FastAPI/Uvicorn, **Ultralytics(YOLO)**, Pillow가 함께 설치됩니다. 트래커를 처음 실행하면 이 폴더에 `yolo11n.pt` 가중치 파일이 없을 경우 Ultralytics가 자동으로 다운로드합니다.

#### 5. 트래커 실행

**데스크톱 모드 (OpenCV 창):**

```bash
python main_ver5.py
```

먼저 시작 튜토리얼이 나오고, 이후 시선/마이크 캘리브레이션(가만히, 조용히 있어야 함)을 거쳐 트래커가 시작됩니다. 창 닫기, `q` 입력, 또는 화면 내 `X` 버튼으로 세션을 종료할 수 있으며, 실제로 완전히 종료되기 전에 하루 종합 평가 화면이 먼저 표시됩니다(다시 `Enter` 또는 `X`를 눌러야 확정 종료됩니다).

**웹 모드 (브라우저, 로컬 전용):**

```bash
python main.py
```

브라우저에서 `http://127.0.0.1:8000`을 **같은 컴퓨터에서** 열고(로컬 웹캠/마이크에 직접 접근해야 하므로) **시작** 버튼을 클릭하세요. 튜토리얼, 캘리브레이션, 트래커 화면 모두 MJPEG 스트림으로 페이지에 표시되며, 페이지에서의 클릭/키 입력은 데스크톱 버전과 동일한 핸들러로 전달됩니다.

## 동작 원리 (요약)

```
책상캠 ──▶ YOLO11n 물체 감지 ──▶ factor (0.4 / 0.8 / 1.0)
얼굴캠 ──▶ MediaPipe 시선/깜빡임/가림/고개방향 분석 ─┐
마이크 ──▶ RMS 기반 소음 감지 ────────────────────────┼─▶ 가중합 집중도 점수 (0~100)
                                                        │
                                최종 점수 = factor × 집중도 점수, EMA로 스무딩
                                                        │
                                ──▶ 실시간 UI(과목 타이머 + 그래프) ──▶ 하루 종합 평가
```

점수 산출 공식, 임계값, 판단 로직에 대한 상세한 기술 분석은 [보고서.md](보고서.md)를 참고하세요. (claude ai 가 작성하였습니다)

|---|---|

## 감사의 말

* 얼굴/눈/고개 방향 기반 집중도 판정 로직의 원형은 [JIYA1220/Concentration-Tracker](https://github.com/JIYA1220/Concentration-Tracker)를 참고했습니다.
* 물체 감지에는 [Ultralytics YOLO11](https://github.com/ultralytics/ultralytics)(`yolo11n.pt`)을 사용했습니다.
* 얼굴/눈 랜드마크 추출에는 [Google MediaPipe](https://github.com/google-ai-edge/mediapipe)를 사용했습니다.
* 본 프로젝트는 **서울과학고등학교 동아리 LTE-ANN** 2학년 7명이 함께 개발했습니다.

## 한계점

* 저희가 웹을 다루는 것에 익숙하지 않아서 css html 대신 파이썬을 사용하였습니다. 양해 부탁드립니다.
* 과목, 누적 시간, 그래프 기록이 메모리에만 저장되어 프로그램을 재시작하면 초기화됩니다.
* EAR, 시선 허용오차, 가림 판정, 소음 민감도 등의 임계값은 실험적으로 정한 값이라 조명/카메라/사용자에 따라 조정이 필요할 수 있습니다.
* 단일 사용자·단일 세션 기준 캘리브레이션이라 사용자별 프로필 저장 기능은 없습니다.
* 책상캠 물체 감지는 YOLO의 `cell phone` / `book` / `laptop` 클래스로 제한됩니다.
* 웹 모드는 로컬 전용으로, 별도 인증이나 다중 세션 지원은 없습니다.
